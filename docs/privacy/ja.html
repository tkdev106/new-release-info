English

このポリシーでは、New Releases の開発者（以下「当方」）が、本アプリにおける情報をどのように取り扱うかを説明します。本アプリにはアカウント、広告、アクセス解析はなく、当方が情報を販売することもありません。

1. 端末内に保存される情報

次の情報はお使いの端末内にのみ保存され、当方に送信されることはありません。

  • 登録したアーティストと、そのアーティストについて見つかった新譜
  • 再生回数（「通知へのアクセス」をオンにした場合）
  • 利用者に表示するおすすめアーティスト
  • 設定

「通知へのアクセス」は、よく聴くアーティストを表示するために、音楽アプリで再生中の情報（アーティスト名とアプリ）を読み取る目的にのみ使用します。通知の内容は読み取りません。この機能は任意で、端末の設定からいつでもオフにできます。

Android のバックアップがオンの場合、これらの情報は Android によって Google アカウントにバックアップされることがあります。

Gemini API に送信されたアーティスト名は、Google が自社の製品や機械学習技術の改善に利用することがあり、人間のレビュアーが閲覧する場合があります。なお、利用者を特定できる情報があわせて送信されることはありません。

当方のサーバーは、同じリクエストに再度応答できるよう、おすすめの結果を最大 7 日間保持します。この結果が利用者と結び付けられることはありません。

不具合の調査のため、当方のサーバーは、受け取ったアーティスト名、返したおすすめ、リクエストの送信元の国を記録し、3日間保存します。この記録に利用者の IP アドレスは含まれません。

3. 第三者への提供

法令に基づく場合を除き、上記の送信先以外に利用者の情報を提供することはありません。

4. 選択可能なこと

  • 「通知へのアクセス」をオフにすると、再生回数の集計を停止できます。
  • アーティスト名を当方のサーバーに送信したくない場合は、おすすめの更新ボタンを押さず、おすすめ通知をオフのままにしてください。
  • 本アプリをアンインストールするか、ストレージを消去すると、端末内の情報はすべて削除されます。

5. 変更

機能の追加などに伴い、このポリシーを改定することがあります。改定した場合は、新しい版を日付とともにこのページに掲載します。
