プライバシーポリシー

New Releases（Android アプリ）
制定日・最終更新日: 2026年11月23日

English

個人開発者 tkdev（以下「開発者」）は、Android アプリ「New Releases」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。本アプリを使う前にお読みください。

1. 基本的な考え方

  • 本アプリにアカウント登録はありません。氏名・メールアドレス・電話番号・位置情報・連絡先などは取得しません。
  • 本アプリが扱う情報は、原則として利用者の端末の中だけに保存され、開発者のもとには届きません。
  • 機能を提供するために外部へ送る情報は、必要な範囲にとどめ、送り先と内容をこのポリシーで明らかにします。
  • 広告の表示、利用状況の解析（アナリティクス）、情報の販売は行いません。

2. 端末の中だけに保存する情報

次の情報は端末の中のアプリ専用の領域に保存され、開発者を含む外部には送信しません（第3項で送信すると定めたものを除きます）。

情報内容・使い道
登録したアーティスト利用者が登録したアーティストの名前・ID など。新譜の確認に使います。
新譜の情報確認で見つかった作品の名前・発売日・ジャケット画像の URL など。一覧・通知・ウィジェットの表示に使います。
再生の集計「通知へのアクセス」を有効にした場合に限り、音楽アプリで再生中の曲のアーティスト名と、再生したアプリの種類、再生の回数・時刻を記録します。「よく聴くアーティスト」の表示と、新譜を開く音楽アプリの選択に使います。
設定などウィジェットの見た目、非表示にした項目、確認の時刻など、アプリの動作に必要な情報。

通知へのアクセスについて

本アプリは Android の「通知へのアクセス」を、音楽アプリが公開している再生中の情報（メディアセッション）を読むためだけに使います。メッセージやメールなど、通知の内容は読みません。この権限は任意で、有効にする前にアプリ内で説明と同意の画面を表示します。端末の設定からいつでも無効にできます。

端末のバックアップ

Android の自動バックアップを有効にしている場合、上記の情報は Android の機能により利用者自身の Google アカウントにバックアップされることがあります。このバックアップは Google が管理し、開発者が見ることはできません。

3. 外部に送信する情報

本アプリは、機能の提供のために次の送り先へ情報を送信します。送信の際、通信の仕組み上、送り先には端末の IP アドレスやアプリ・OS の種類などの技術的な情報も伝わります。各送り先での取り扱いは、それぞれのプライバシーポリシーに従います。

送り先送る情報目的
Apple
（iTunes Search API・Apple Music の公開ページ）		検索した語、登録したアーティストの ID、ストアの国（端末の言語から決めます）アーティストの検索、新譜・発売予定の確認、アーティスト画像の取得
開発者が運営する中継サーバー
（Cloudflare, Inc. の Cloudflare Workers 上で動作）		登録したアーティストの名前（最大30件）、Play Integrity の確認用トークン（Google Play から入れた版のみ）「おすすめアーティスト」の取得。利用者が更新ボタンを押したときだけ送信します
Google
（Gemini API）		中継サーバーが、上記のアーティスト名だけを転送します。端末や利用者を識別する情報は転送しません似たアーティストの候補を作るため
Google
（Play Integrity API）		アプリと端末が正規のものかを確かめるための情報（Google Play サービスが生成します）中継サーバーの不正利用の防止
  • Gemini API は無料の利用枠で使っています。Google の利用規約により、送信した内容（アーティスト名）と生成された結果は、Google のサービスの提供・改善に使われることがあり、品質向上のために人が確認することがあります。アーティスト名以外の情報は送りません。
  • 本アプリが表示するおすすめは AI が作った候補を Apple のカタログで確かめたものですが、正確さや好みに合うことは保証できません。
  • 新譜をタップしたときなど、利用者の操作で他のアプリ（音楽アプリ）やブラウザを開く場合、その先での情報の取り扱いは各サービスのポリシーに従います。

送り先のプライバシーポリシー: Apple、 Cloudflare、 Google、 Gemini API 利用規約

4. 中継サーバーでの取り扱いと保存期間

  • 同じアーティストの組み合わせへの結果を返すため、アーティスト名の組み合わせから作った値と、おすすめの結果を最長7日間キャッシュします。利用者を識別する情報とは結び付けません。
  • 連続した呼び出しの制限と不正利用の防止のため、IP アドレスを一時的に使います。また、障害対応のため、通信の記録が Cloudflare の仕組みで短期間保存されます。
  • 全体の1日の利用回数を数えますが、回数だけで、誰が使ったかは記録しません。
  • 開発者は、これらの情報を、利用者個人を特定する目的で使いません。

5. 情報の利用目的

開発者は、取り扱う情報を次の目的にだけ使います。

  • 本アプリの機能（新譜の確認・通知・ウィジェット・よく聴くアーティスト・おすすめ）を提供するため
  • 不正利用を防ぎ、サービスを安定して提供するため
  • 不具合への対応やお問い合わせへの回答のため

6. 第三者への提供

開発者は、第3項の送信を除き、利用者の情報を第三者に提供しません。ただし、法令に基づく場合など、法令で認められる場合はこの限りではありません。

7. 利用者ができること

  • 再生の集計を止める: 端末の設定で本アプリの「通知へのアクセス」を無効にしてください。
  • おすすめを使わない: おすすめの更新ボタンを押さなければ、中継サーバーには何も送信されません。
  • 通知を止める: 端末の設定で本アプリの通知を無効にできます。
  • 情報を消す: 端末の設定で本アプリのストレージを消去するか、本アプリをアンインストールすると、端末内の情報はすべて消えます。

8. 安全管理

外部との通信は暗号化（HTTPS）して行います。中継サーバーの鍵などの秘密の情報はアプリに含めず、サーバー側で管理します。

9. 対象年齢

本アプリは18歳以上の方を対象としており、子ども向けではありません。

10. 提供地域

本アプリは、欧州経済領域（EEA）・英国・スイスでは提供していません。これらの地域からはおすすめの機能を使えません。

11. このポリシーの変更

開発者は、機能の追加や法令の変更などに応じて、このポリシーを変更することがあります。取得する情報や送り先が変わる場合は、このページで内容と更新日を示し、重要な変更はアプリの更新内容などでもお知らせします。

12. お問い合わせ

このポリシーや本アプリでの情報の取り扱いについては、Google Play の本アプリのページに記載のデベロッパーのメールアドレス、または GitHub の Issues までご連絡ください。
